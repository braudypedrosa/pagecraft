## Required journeys

- [ ] Install and activate Pagecraft Theme and Builder from the candidate ZIP files.
- [ ] Upload a package as a new draft; verify local page, media, clean URL, desktop, tablet, and mobile output.
- [ ] Edit and save in Pagecraft; verify WordPress revision, preview, publish, keyboard access, console, and network health.
- [ ] Import again as a new page; confirm the original remains unchanged and media deduplicates.
- [ ] Explicitly replace a prior copy; confirm a recoverable revision exists before the replacement.
- [ ] Convert Pagecraft navigation to a native WordPress menu; test hierarchy, custom/external links, CSS classes, and new-tab behavior.
- [ ] Connect a Pagecraft account, browse projects/pages, preview, manually import, disconnect, and confirm imported content remains.
- [ ] Simulate revoked credentials; confirm safe failure and a reconnect action with no partial import.
- [ ] Make Pagecraft Cloud unreachable; confirm published WordPress pages and local assets remain available.
- [ ] Deactivate Builder; confirm public pages, header/footer, CSS, interactions, clean URLs, and media remain available.
- [ ] Re-enable Builder; confirm editing resumes without content loss.
- [ ] Uninstall Builder; confirm WordPress-owned pages, menus, media, revisions, and files are retained.
- [ ] Confirm unsupported CMS/custom-code packages fail with actionable errors and no partial page.
