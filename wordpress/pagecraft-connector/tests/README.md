# Connector tests

The unit suite runs the protocol boundaries without booting WordPress. Its bootstrap supplies
small WordPress-compatible stubs only for APIs used by those boundaries; it does not pretend to
test posts, media, rewrites, cron, REST routing, or database transactions.

```bash
cd wordpress/pagecraft-connector
composer install
composer test
```

The repository-level Docker suite in `wordpress/dev` owns integration behavior against real
WordPress 6.6 and PHP 8.1 targets. Run it after the unit suite:

```bash
bash wordpress/dev/bootstrap.sh
bash wordpress/dev/test.sh
```

The shared signed golden release fixture is generated by the Node release-contract tests and is
consumed here and by the Docker suite. Tests must fail, rather than fabricate a fallback, when its
schema changes incompatibly.
