# Font and colour rotation for the Pagecraft collection

The 24 new premade sites need deliberate variety in typography and colour as well as composition. Use `premade-sites/style-rotation.json` as the candidate pool, existing-style inventory and usage ledger. This is an authoring review contract, not a customer-facing runtime theme switcher.

## Before each concept

1. Inspect the existing-style inventory and all recorded choices. Choose industry-appropriate families from the pool or propose a justified addition that Pagecraft supports.
2. Present at least two meaningful colour/type options. Preserve an already liked layout and imagery when the request only changes styling.
3. Avoid consecutive reuse of the same font pair or dominant palette. Do not repeat an exact font-pair and palette combination across the 24 sites. Compare complete rendered appearance; a tiny hue change does not count as variety.
4. Record the exact user-selected families, weights, palette roles and approval source in the usage entry. Dental A2 is selected for its concept, layout direction, Sky and Ice palette, Figtree headings and Source Sans 3 body. Exact exported assets, the built site and catalog package still need their separate approvals. Individual font families and colour families may recur deliberately; every site does not need a novel font.
5. Carry selected values into editable native Pagecraft tokens and supported controls. Verify actual font loading, text and button contrast and desktop/mobile output before acceptance.

## Initial choices

Eight font pairings and six palette families are candidates. All 15 distinct font families are present in Pagecraft's native `Core.GF` list. This proves builder availability, not a deployed font-loading pass. The initial three dental boards propose Sora/Public Sans, Figtree/Source Sans 3, and Nunito Sans/Work Sans. The exact proposed colour tokens and computed contrast are saved with those boards. Raster generation approximates letterforms and colour reproduction; exact CSS/font and asset checks follow user selection.

The audit found repeated cream/green/serif language across several existing sites. This is a collection-level caution against default repetition, not a ban on those colours or type styles. The current user prefers Dental concept A's composition, with typography and colour revision. No native site build or catalog promotion follows until the relevant asset and design approvals.
