# Pagecraft release-readiness QA

**Date:** 26 August 2026
**Production:** `https://build.itspagecraft.com`
**Public test site:** `https://pagecraft.braudyp.dev/braudy/`
**Verdict:** **CODE GATE PASS — PRODUCTION RELEASE HOLD**

The confirmed engine defects from this audit have been fixed. The current integrated suite passes **886 tests across 18 files**, the legacy standalone editor and TypeScript successor both build, and a fresh built-in-browser pass confirms the editor and generated customer site work without console errors. The Passenger application, Supabase gateway, and Resend credential rotation are deployed and production smoke checks pass. Production remains on hold for the archive-based recovery gate, live-content configuration, and Cloudflare credential rotation below.

The restore drill did not edit production project content or restore data into production; all recovery writes were isolated to a disposable Supabase project. A controlled owner magic-link email was sent after the Resend rotation, creating the expected additional production `login_links` row.

## Remediation status

| Audit item | Current status |
|---|---|
| PC-QA-001 persistence | **Fixed locally.** Create, save, and restore now migrate, validate, and render before committing. Failed preflight does not advance or replace the stored document. |
| PC-QA-002/003 media | **Fixed locally.** Hosted asset paths are collision-safe and ID-suffixed, legacy URLs remain readable, listing is metadata-only, and authorized deletion is durable through the gateway and server. |
| PC-QA-004 hosting | **Fixed locally.** Hosted asset, Open Graph, and JSON-LD paths remain under the site's shared prefix on home, nested, detail, and paginated URLs. |
| PC-QA-005 forms/privacy | **Fixed locally.** Only credential-free absolute HTTPS endpoints produce active forms. Missing, relative, protocol-relative, credential-bearing, and non-HTTPS actions publish inert and are reported by Review. |
| PC-QA-006 editor safety | **Fixed and browser-verified.** Dialogs trap/return focus, Escape closes the active dialog, and Delete/shortcuts no longer mutate the canvas behind it. |
| PC-QA-007 Preview | **Fixed and browser-verified.** Preview runs the same Tabs, Gallery, Code copy, Slider, Video facade, navigation, and animation runtime as exported pages. |
| PC-QA-008 performance | **Deployed and remeasured.** Public lookup caching is bounded, authenticated/history work is bulked, and repeated gateway/N+1 calls were removed. Warm production TTFB measured about 1.12 s median; one 3.799 s cold-start outlier remains to monitor. |
| PC-QA-009 recovery | **Partial operational evidence; release gate remains open.** An encrypted logical JSON snapshot was restored row-for-row into a fresh disposable Supabase project, matched production's schema/access signature, passed gateway and Node smoke checks, and was paused after verification. This does not prove the scheduled `supabase db dump` archive or `tools/restore-supabase.sh`; that official drill is still required. |

A restricted Resend key delivered the owner login email and the retired key was revoked and rejected. |

The related medium/low defects were also addressed: unique collection controls, real inspector drop handling, picker deletion, complete undo transactions, Add/Navigator/field/dialog accessibility, exactly one complete `<main>` plus skip link, canonical clean hosted URLs, safe raw-text-aware HTML rewriting, improved Review findings, metadata-only media reads, deploy-source completeness, stronger host/email/role/version validation, authenticated `private, no-store`, HSTS, corrected copy, and clearer device/production labels.

## Original release blockers

The table below is preserved as the evidence baseline from the original audit; use the remediation table above for current status.

| ID | Severity | Area | Confirmed failure | Evidence / impact |
|---|---|---|---|---|
| PC-QA-001 | High | Persistence | Malformed documents are written before rendering is validated. | A local API create with `pages:[{}]` returned `409` but left a site behind. A save returned `500`, advanced the version, and persisted the invalid document. A failed render can therefore corrupt the latest customer state. See `server/src/app.ts:313`, `server/src/app.ts:375`, and `app/src/core/index.ts:4746`. |
| PC-QA-002 | High | Media | Different uploads with the same filename receive the same immutable public path. | Two `photo.png` uploads both mapped to `assets/photo.png`; lookup returned the first asset. Responses are cached for one year with `immutable`, making the wrong image persist. See `app/src/core/index.ts:2525` and `server/src/app.ts:827`. |
| PC-QA-003 | High | Media | Deleting a server-backed image only removes it from browser memory. | The editor exposes Delete and Remove unused, but no server `DELETE` asset route exists. A local authenticated deletion returned `404`; the stored image returned after reload. See `builder.html:1713` and `server/src/app.ts:586`. |
| PC-QA-004 | High | Hosting | Shared-host assets can 404 at the clean homepage URL. | Output uses relative `assets/foo.png`. `/braudy/index.html` redirects to `/braudy`, where the browser resolves that as `/assets/foo.png`, the editor host's reserved asset prefix, instead of `/braudy/assets/foo.png`. `/braudy/` works. The live demo hides this because its images are inline placeholders. |
| PC-QA-005 | High | Forms/privacy | An unconfigured form performs a GET to the current page. | Generated markup has a normal `<form>` with no `action` or `method`. Browsers then put submitted values in the URL/history/logs. The review currently says this will silently do nothing, which is incorrect. The renderer must disable submission or require a safe endpoint. |
| PC-QA-006 | High | Editor safety | Global shortcuts mutate the canvas behind normal dialogs. | In the disposable editor, a Heading was selected, Project settings was opened, and Delete removed the Heading while the dialog stayed open. Escape also failed to close the dialog while Project name had focus. See `builder.html:4240-4340`. |
| PC-QA-007 | High | Preview | Preview does not run the scripts that exported interactive widgets use. | Tabs remained on the first tab after click, Gallery lightbox clicks showed “External links open…” with no dialog, and a Code copy control stayed hidden. The same gap affects Slider controls, Video facade playback, and scroll animations. Nav is the exception because the builder manually wires it. Exported pages include the scripts; Preview does not. |
| PC-QA-008 | High | Performance | The production gateway is too slow for a launch surface. | Five `/braudy` requests had a median TTFB of **3.716 s**. In 98 successful recent gateway calls, Supabase Edge execution was p50 **2.683 s**, p95 **3.888 s**, max **4.41 s**. Public rendering always performs a remote lookup before checking the rendered cache, and authenticated flows make sequential calls. Production History took about 6.5 seconds to populate in this audit. See `server/src/app.ts:648-666`. |
| PC-QA-009 | High | Recovery | There is no tested customer-data backup/restore plan. | The live Supabase organization is on Free; the repository contains no scheduled encrypted off-site dump, retention policy, or restore drill. Supabase documents automatic daily backups for Pro, Team, and Enterprise and recommends regular off-site CLI dumps for Free projects: [Supabase Database Backups](https://supabase.com/docs/guides/platform/backups). |
| PC-QA-010 | High | Live demo | All six visible conversion CTAs on `/braudy/` are inert. | “Start a project,” “Get started,” “Grow with us,” and “Talk to us” render as `button type="button"` without a destination or handler. They are keyboard-focusable but do nothing. This is a live-project configuration problem and a launch-blocking first impression; the review system does not flag it. |
| PC-QA-011 | High | Picker state | Pressing Enter on a picker's Close control can resolve the hidden confirmation path as `true`. | Picker mode hides the confirmation button, but the ask-layer Enter handler still clicks it. | PC-QA-012 | High | Authentication operations | Email failure handling can report success or expose a login link in logs. | The sign-in client displays “Check your email” without checking `response.ok`. ## Live demo configuration problems

These are not all engine defects, but they must be corrected before using `/braudy/` as Pagecraft's customer-facing proof:

- About, Work, and Contact all return to the homepage top instead of a section or page.
- Six CTA buttons have no destination.
- Three images are placeholders, have no intrinsic dimensions, and are all lazy-loaded, including the hero/LCP candidate.
- Site URL is empty, so canonical, `og:url`, JSON-LD, and sitemap output are absent.
- The public HTML immediately requests Google Fonts. Decide whether to self-host fonts or document the privacy/consent position.

## Important test limitations

- A finite QA run cannot prove every possible combination of 223 widget-specific controls, 15 shared Style controls, breakpoint overrides, state variants, bindings, and arbitrary user content. This audit inventoried all control families, clicked every Add/template entry, exercised a representative of every renderer family, and paired that with 886 automated tests.
- Production did not contain a real uploaded image, Form, Gallery, Video, CMS list/pagination, custom domain, or multi-user invite flow. Those were exercised in a disposable local project or inspected at the API/source boundary instead of modifying the live project.
- No production form was submitted, version restored, asset/site deleted, collaborator invited, hostname changed, or export published/downloaded. One controlled owner login email was sent to prove the rotated SMTP path and was confirmed delivered in Resend.
- Performance figures are repeatable request/Edge timings from the current Manila/Singapore route, not field Core Web Vitals.
- Concurrent editing and multi-worker invalidation still need dedicated staging exercises. Backup/restore now has a repeatable local command-path test plus an isolated logical JSON/MCP restore, but the real encrypted `supabase db dump` archive and `tools/restore-supabase.sh` drill remain an explicit production gate.
