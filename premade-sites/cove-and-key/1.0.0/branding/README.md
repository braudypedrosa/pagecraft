# Cove & Key logo assets

The canonical graphic mark combines a cove, wave and key. SVG masters contain outlined Manrope lettering and no raster elements. Use logo-light on navy; logo-dark or logo-blue on white. Keep clear space equal to half the symbol height. Use the symbol alone below 160px lockup width; test the favicon at its actual size.

SVG variants: light, dark, blue, black. Transparent PNG lockups: 320, 640, 1280px. Icons: 32, 180, 192, 512px. Board and social exports derive from canonical vectors. The bundled Manrope license is in typography/.

Run build.py using Python with fonttools to regenerate masters from the repository Manrope font. The website uses native Pagecraft global font controls. The social imagery is for the fictional template, not a real rental business. PMS and receiving-service configuration are separate from branding.
