# Cove & Key

Reusable native Pagecraft vacation-rental template for travelers comparing coastal homes. User selected B — Horizon Club and authorized rebuilding the rejected first draft against that direction.

Eight pages: Home, Stays, three property details, The Coast, Our Story, Contact. Required: graphic logo, native hero inquiry form, native property slider, property booking placeholders, contextual CTAs and reviews.

All homes, photographs, amenities and reviews are illustrative demonstration content. There are no confirmed real-property facts or verified reviews. Keep disclosures until replaced with verified content.

Native editable nodes and node style controls implement layout. No injected custom CSS or layout embeds. Forms use an empty external action and remain disabled. User explicitly requested placeholders now, a real PMS later. No provider or receiving endpoint is supplied. Live inquiries and bookings require configuration and actual receipt/flow verification.

This is a local draft. Cloud and WordPress host acceptance and catalog promotion remain separate gates. No release approval has been given.
