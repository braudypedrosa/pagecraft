# Salt House complete redesign

User feedback: “Terrible site. Are we serious here?” This rejects the completed Coastline candidate, not a global design rule. Prior agent passes are retained as historical assessments, not user approval.

Direction: Mediterranean retreat, Outfit typography, limestone paper, dark olive, terracotta actions. Cinematic photograph with restrained centered copy; horizontal property dossiers; a contiguous coastal photo essay; image-backed closing invitation.

Native policy: Pagecraft sections, grids, component properties, native gallery, accordion and form. Native hover, menu disclosure, gallery and FAQ interactions replace unsupported GSAP sequencing. Native scroll entrance markup failed the WordPress importer and was removed. No custom CSS, injected JavaScript or fabricated reviews.

Composition: header compact cream navigation; hero centered copy over contextual cove photograph; text anchor centered opening then property-bound captions; inventory sequential image-and-facts dossiers; CTA in-flow property links and honest inquiry; footer photographic invitation with compact colophon.

AIDA: attention = cove and holiday promise; interest = rooms and two homes; desire = coastal image essay; action = choose a home and send a configured inquiry. Dense media grid uses two columns and one complete row; no filler cells. Heading target <=3 lines, body >=17px and metadata >=14px.

The generated component suggestions are filtered through intentional-web-design: inline heading pictures, promotional marquee, and hover-expanding comparison panels are rejected. Native disclosure questions and a stable photo gallery serve the actual journey.

Previous checksum acceptance does not apply to this redesign. Both-host editability verification and final user visual approval remain pending.

Rendered verification: all six page layouts inspected in the built-in browser. Evidence is in evidence/redesign. This is an agent assessment; user approval is pending.
