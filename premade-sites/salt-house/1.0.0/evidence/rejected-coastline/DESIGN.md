# Salt House — Coastline

Visual thesis: sun-bleached coastal homes, blue ink and practical property information, led by a large brand and a full-width photograph.

The homepage moves from an oversized centered wordmark to an uninterrupted terrace panorama, then a paired property comparison on sand. The village section provides a quieter image-and-reading composition. Property pages use clear facts beside a narrative, a distinct secondary photograph, and a direct route to planning. The coast page provides a loose sequence rather than fabricated local recommendations. The planning page uses native disclosures and a real, explicitly unconfigured inquiry form.

DM Sans is the single family. Sea ink and sea blue anchor text/actions; chalk and sand distinguish surfaces. Shared text styles control sizes and responsive hierarchy. Photographs, spacing and alignment carry the visual identity; there are no ornamental card frames or shadows.

Native interactions provide functional motion: mobile menu disclosure, gallery lightbox and FAQ expansion. No external animation runtime or hidden CSS is introduced. Keyboard focus remains supplied by Pagecraft's native controls.

Review history: user selected the recommended Coastline direction by replying “proceed.” Independent review rejected repeated hero photographs in the property galleries and the mobile cottage crop. Those sections now use a distinct bedroom/exterior view and native 80% horizontal image alignment. Final independent review passed both isolated hosts. This is not final user approval.

General visual criteria remain in intentional-web-design; Pagecraft-specific compatibility and evidence are recorded in workflow.json. Screenshots and their provenance stay in the project review library.
