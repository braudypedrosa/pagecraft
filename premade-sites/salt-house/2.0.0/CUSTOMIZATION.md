# Customizing Salt House (salt-house@2.0.0)

## Identity, Typography & Palette
- **Site Name & Metadata**: Open **Settings › General** to replace **Salt House**, update the favicon (`asset:favicon`), and set your social preview image.
- **Typography**: Heading font and body font are governed globally via **Settings › Typography** without pinned heading-level font overrides.
- **Color Tokens**: Adjust brand, surface, ink, muted and border tokens under **Global Styles › Colors** to re-theme all 6 pages simultaneously.

## Reusable Components & Interactive Widgets
- **Reusable Cards**: Update the shared card component definition or edit individual component instance properties (title, metadata, description, photograph, destination link) in the Inspector.
- **Tabs, Carousels, Lightbox Galleries, Tables & Accordions**: Select any interactive widget on the canvas to edit tab panels, slides, gallery captions, table rows, or FAQ items natively.

## Inquiry Form Setup
- **Pagecraft Cloud**: Submissions are captured automatically when published on Pagecraft Cloud.
- **Portable / Self-Hosted HTML**: Set the form's HTTPS `action` endpoint in the Inspector and complete a test submission receipt before accepting live inquiries.
