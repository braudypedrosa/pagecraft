# Commonwell Homekeeping design plan

## Direction

Commonwell is a fictional residential-cleaning brand built around the idea of an open doorway and a home ready to be used. The design uses deep pine, warm paper, oat, and marigold with a serif-led editorial voice. It avoids clinical blue, stock review claims, decorative counters, and generic equal-card repetition.

The persisted UI/UX Pro Max result recommended calm editorial typography, high contrast, a clear hero-to-CTA journey, and restrained motion. Those fit the service. Its default navy SaaS palette and generic feature pattern do not fit a warm household brand, so the native Pagecraft tokens adapt the color direction and section sequence while retaining contrast, 44px controls, readable body type, responsive hierarchy, focus states, and reduced-motion-safe static output.

## Page and section plan

- **Home:** joined editorial/photo hero; three-part service promise strip; open service ledger; room-by-room photo story; useful visit expectations; illustrative package comparison; photo-backed quote prompt.
- **Services:** concise page introduction; three detailed service bands; clearly labelled illustrative package comparison without prices; boundaries and add-on notes; quote prompt.
- **Approach:** wide bedroom scene; top-aligned principles; visit rhythm without decorative numbering; home preparation and access notes; products still life; quote prompt.
- **Contact:** quote-inquiry context; explicit unconfigured-state notice; native form; privacy and response guidance; service-area placeholder without a real address.
- **Shared:** graphic logo, native mobile-collapsing menu, tokenized type and colors, compact branded footer.

## Responsive intent

Desktop uses joined panels, open ledgers, and deliberate image scale changes. Tablet reduces gaps while retaining side-by-side moments where legible. Mobile collapses all content to one column, keeps controls at least 44px high, changes hero reading order to copy then image, and uses the native collapsed navigation.
