## Reading rules

The controls below are taken from the current module inspector definitions in `app/src/core/index.ts`. “Accepted” means an existing native report shows the named setting or finite option surviving save/reopen or rendering in the named runtime. “Partial” means the report covers only a subset or a runtime without inspector persistence. “Unproven” means no current native report was found for the named control. Source contracts, DOM-only reports, and WordPress capability declarations do not promote a control to native acceptance.

These shared controls remain separate from each module’s Content controls.
