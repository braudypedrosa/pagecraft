## Current control contract

[Button definition](../../app/src/core/index.ts:831): Label, Text style, Link/new-tab, four Variants (Solid/Outline/Ghost/Text link), four Trailing icon choices (None/Arrow/Check/Plus), responsive Alignment (Left/Centre/Right/Fill), and conditional Position inside a Column (Default/normal flow/push bottom). Direct Style: Background, Text colour, Size, Weight, Radius, Letter spacing, Transform. Shared capability panels add spacing, decoration, effects, typography and animation; this is not an exhaustive Advanced-setting acceptance inventory.

[Update typography](../../app/src/ui/inspector/Controls.tsx:784) deliberately shares typography only. Spacing, backgrounds and borders stay local; peer overrides remain. Reusable **class styles** are a different sharing path. A mixed-setting update must test both what propagates and what correctly stays local—the original report cannot be judged solely by whether two buttons look identical.

## Next customer flow — highest-value gaps

1. **Recreate the original confusion in one continuous session.** Add two page buttons and one component instance; give them distinct Solid/Outline/Text-link variants and labels. On the first, type size/weight/text colour plus padding/background/radius sequentially, then choose Update typography. Cancel once: peers/history unchanged. Confirm once: typography follows; local surfaces, variants, labels, links and icons do not change. Include a peer with an explicit text-size override and an unrelated button using another text style. 2. **Carry that same fixture through responsive inheritance.** Set Desktop typography, Tablet size and Mobile size/colour. Clear only Tablet size and verify Mobile remains explicit while Tablet inherits Desktop; clear Mobile and verify the visible inherited value matches rendered output. Update typography, save/reload, and check only changed fields. Do not repeat the accepted class-radius matrix without a discrepancy.
3. **Finish the sharing lifecycle.** Detach one peer without moving its appearance, change the shared typography again, and verify the detached peer stays unchanged. Use Undo/Redo through detach/update, then save/reload. If a reusable class is used for shared surfaces, test that path explicitly and keep it separate from text-style updating.
4. **Exercise direct controls while preserving the same edited button.** Cycle the remaining variant/icon choices, all four alignments and Column-only Position; use a tall neighbouring column so push-bottom has a visible effect. Move the button out of the Column and check the Position control disappears without unintended layout. Check internal-page/anchor navigation, new-tab behaviour and email/phone hrefs without invoking external apps; record empty-link expectations.
5. **Close with interaction and host proof.** Tab/activate an internal destination; compare Hover/Focus/Resting and reload.
